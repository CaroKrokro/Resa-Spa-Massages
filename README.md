# Flux Salette (démonstration)

Démonstration du parcours de réservation spa et massages du Couvent de la Salette : demande client, validation par les masseuses (« Je prends » / « Non »), pilotage de Stéphanie, ouverture et fermeture de créneaux, décompte mensuel par masseuse.

C'est une page unique (`index.html`), sans installation. Les SMS, paiements et factures sont simulés, les clients sont fictifs. Les données sont gardées en mémoire dans le navigateur et reviennent à zéro au rechargement.

## Mettre en ligne avec GitHub Pages
1. Créer un dépôt sur github.com (par exemple `flux-salette`).
2. Déposer `index.html` et `README.md` à la racine (« Add file » puis « Upload files »).
3. Dans « Settings », « Pages », choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
4. L'adresse du site apparaît au bout d'une minute environ : `https://<votre-compte>.github.io/flux-salette/`.

La charte graphique (couleurs, police, photos) sera affinée plus tard.
